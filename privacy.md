This covers "Moxy gws", a private tool that reads and manages the site owner's own Google accounts. It is not offered to the public.

### What it accesses

With the account owner's consent, the tool can access Gmail, Google Calendar, Drive, Sheets, Docs, Tasks and Contacts for the owner's own accounts.

### How data is used

Data is used only to carry out the owner's requests. It is not sold, shared with third parties, or used for advertising.

### Storage

Sign-in tokens are stored encrypted on the owner's own machine. Access can be revoked at any time from [Google Account permissions](https://myaccount.google.com/permissions).
